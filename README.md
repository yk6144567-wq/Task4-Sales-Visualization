# Sales Data Visualization & Storytelling

**Task 4 | Data Analytics Project**

## Project Overview

This project analyzes monthly sales, profit, and order data using Python. Visualizations are used to identify trends, compare business performance, and communicate insights through a clear business story.

## Objectives

* Analyze monthly sales and profit.
* Identify the highest-performing month.
* Visualize trends using charts.
* Develop actionable business recommendations.

## Tools & Technologies

* Python
* Pandas
* Matplotlib
* Google Colab

## Dataset

The sample dataset contains 12 months of data with four columns:

* **Month:** Month of the year
* **Sales:** Monthly sales value
* **Profit:** Monthly profit value
* **Orders:** Number of orders

**Note:** This is illustrative practice data, not verified real-company data.

## Visualizations

1. **Monthly Sales Trend:** Shows how sales change throughout the year.
2. **Monthly Profit Comparison:** Compares profit across all months.
3. **Sales vs Profit Analysis:** Explores the relationship between sales and profit.

## Key Findings

* **Total Sales:** Rs. 300,000
* **Total Profit:** Rs. 66,800
* **Total Orders:** 2,410
* **Profit Margin:** 22.27%
* **Highest Sales Month:** December
* **Highest Profit Month:** December

## Business Recommendations

* Investigate the strategies used in high-performing months.
* Monitor costs and profit margins alongside sales.
* Use monthly demand trends to plan inventory and marketing.
* Collect product, region, and expense data for deeper analysis.

## Conclusion

This project demonstrates how data visualization can turn a dataset into meaningful business insights and support data-driven decisions.
